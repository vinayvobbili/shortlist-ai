# Senior Data Engineer (GCP)

Relecloud Analytics is hiring a Senior Data Engineer to own our batch and streaming data platform on Google Cloud. You'll work with analytics and ML teams to deliver reliable, well-modeled data.

## What you'll do
- Design, build and operate data pipelines on Google Cloud Platform
- Orchestrate workflows with Airflow (Cloud Composer)
- Build streaming ingestion for event data
- Improve data quality, testing and observability

## Requirements
- 5+ years of professional data engineering experience
- Strong Python and SQL
- Hands-on experience with BigQuery and Dataflow (or Apache Beam)
- Production experience with Apache Airflow

## Nice to have
- Apache Spark
- Streaming systems such as Pub/Sub or Kafka
- Data quality tooling (Great Expectations, dbt tests)
- Google Cloud Professional Data Engineer certification

We offer hybrid work, a learning budget, and great coffee. Relecloud is an equal opportunity employer.
