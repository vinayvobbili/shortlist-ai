# Data Engineer (AWS)

Tailspin Analytics is hiring a Data Engineer to build and run the pipelines behind our reporting and machine-learning platforms.

## What you'll do
- Build batch and streaming pipelines on AWS
- Own orchestration and data-quality checks for core datasets
- Work with analysts to model data in the warehouse

## Requirements
- 3+ years of professional data engineering experience
- Python
- SQL
- Apache Spark
- Apache Airflow (self-hosted or MWAA)
- Hands-on experience with AWS data services such as Glue, EMR, Redshift or Kinesis

## Nice to have
- Streaming with Kinesis or Kafka
- dbt
- Terraform
- An AWS certification

We offer flexible hours, a learning budget and an energetic, young team.
