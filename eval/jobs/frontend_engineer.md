# Frontend Engineer

Lucerne Learning builds reading apps used by two million students. We're hiring a Frontend Engineer to join our web team.

## You will
- Build accessible, responsive features in our React app
- Write tests that keep releases safe
- Work closely with product designers on our design system

## You have
- 2+ years of professional web development experience
- JavaScript and TypeScript
- React
- Automated testing experience (Jest, Cypress or Playwright)

## Bonus points
- Node.js
- Web accessibility (WCAG) experience
- Experience contributing to a design system

Recent graduates of top universities are especially encouraged to apply.
