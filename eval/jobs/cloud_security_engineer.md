# Cloud Security Engineer

Adventure Works Cloud is hiring a Cloud Security Engineer to secure a fast-growing AWS footprint.

## Responsibilities
- Design guardrails and detections across 200+ AWS accounts
- Automate security reviews and remediation
- Partner with the incident response team on cloud incidents

## Required qualifications
- 4+ years of security engineering experience
- Hands-on AWS security experience (IAM, GuardDuty, Security Hub or similar)
- Infrastructure as code with Terraform or CloudFormation
- Python

## Preferred qualifications
- AWS Certified Security – Specialty
- Incident response experience
- SIEM experience (Microsoft Sentinel or Splunk)
- Kubernetes security

Must be able to lift 25 lbs and be available for occasional on-call.
